# نظام التصميم — «أسود دافئ + ذهب مطفي» (v3، 2026-10-01)

مرجع الجودة الذي طلبه المالك: keifaldiafa.com (أسود #0D0D0D + ذهب #C5A059، خط أميري، صورة بطولية، كثافة متوازنة).

## القواعد الصارمة
1. **لا إيموجي في أي واجهة.** المحتوى المصدر (`content/ar/*.json`) يبقى بالإيموجي ليسهل على المترجمين، والبناء يحوّل كل `icon` إلى أيقونة خطية عبر `book/icons/map.json` (165 إيموجي ← 180 أيقونة Lucide، رخصة ISC). واتساب من Simple Icons (CC0).
2. **الشعارات بدل الإيموجي:** 10 شعارات (`arch` قوس البيت النجدي، `star8`، نخلة، هلال، زهرة، جوهرة، ريشة، تاج، غصن، بيت). أيقونات الشاشة الرئيسية PNG بقياس 180 و512 قابلة للقص (maskable). الطلبات القديمة التي تحمل إيموجي تُحوَّل تلقائياً (`LEGACY_EMBLEM`).
3. **الخطوط مستضافة ذاتياً ومقتطعة:**
   - Amiri Bold (43KB) للعناوين.
   - Noto Naskh Arabic متغيّر بأوزان 400–700 (22KB) للنص.
   - التحميل المسبق `preload` و`font-display:swap`، مع خط احتياطي بمقاسات مضبوطة لتقليل الإزاحة (CLS).
4. **الكتاب له وضعان:** «ليلي» (الافتراضي، أسود وذهب) و«ورقي» (عاجي وحبر بنّي)، ومعهما 4 أحجام خط. يُحفظان على الجهاز ويُطبَّقان قبل أول رسم فلا يحدث وميض.
5. **أهداف اللمس 40px على الأقل** (تتحقق منها الاختبارات)، وتُحترم إعدادات `prefers-reduced-motion`، وكل الأيقونات `aria-hidden` ومعها نص أو `aria-label`.

## الملفات
- `platform/src/ui.ts`: CSS الموقع، و`head()` (SEO)، والرأس والتذييل، وفئة `Icons` التي لا تضمّن إلا الرموز المستخدمة.
- `platform/src/pages.ts`: الصفحات (البيع، الطلب، الحالة، الخصوصية، الشروط، الإدارة).
- `book/templates/book2.html` و`book/core/app.js`: الكتاب.
- `tools/icons.mjs` و`tools/images.py`: تولّد كل الأصول (sprite، الشعارات، favicon، أيقونات PWA، صورة OG، صورة الواجهة بصيغ AVIF وWebP وJPEG، وملف `assets.gen.ts` ببصمات المحتوى).
  - التشغيل: `cd tools && npm i && node icons.mjs`
- صورة الواجهة مولّدة بالذكاء الاصطناعي (nano-banana-pro) ومحفوظة في `tools/src/hero.png`، وليست صورة مخزون تجارية.
