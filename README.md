# غيداء — «كتاب البيت» 🌸

> كتاب فاخر يُصنع لكل بيت: **قواعد البيت، جدول العاملة، السلامة، الضيافة، وحقوقها** — بلغتها الأم وبالعربي، **وكل جملة بصوت**. يُثبَّت على جوالها ككتاب باسم البيت، ويعمل **بدون إنترنت**، ومحمي برمز وبصمة.

**الحالة (2026-10-01)**: المحرك v2 + منصة البيع جاهزان ومختبران آلياً (128 فحصاً أخضر). الأمهرية كاملة. التالي: نشر عام + اختبار أجهزة حقيقية + لغات إضافية. انظر `docs/HANDOFF.md`.

## كيف يعمل
```
ربة البيت ──► الموقع: لغة العاملة · اسم الكتاب · قواعد البيت · الجدول (يُرفض إن خالف النظام)
           ──► تحويل + رفع الإيصال ──► قراءة آلية (رؤية) + 7 فحوص ──► اعتماد (آلي أو بضغطة)
           ──► رابط خاص + رمز (PWA يعمل offline) + ملف HTML واحد للواتساب
العاملة   ──► تفتح بلغتها · تسمع كل جملة · «ردودي» تنطق العربي لربة البيت · طوارئ مفتوحة دائماً
```
